# Full Stack Web Development Repository

This repository is organized for coursework submissions and project artifacts.  
You can upload your PDFs, ZIP extracts, screenshots, and source files directly using GitHub's **Add file → Upload files** option.

## Repository Structure

- **Observation/**
  - **PDFs/**: Place observation-related PDF documents.

- **E-Record/**
  - **PDFs/**: Place e-record related PDF documents.

- **Assignments/**
  - **Assignment-1/**
    - `README.md`: Notes and submission details for Assignment 1.
  - **Assignment-2-Individual-Project/**
    - `README.md`: Overview and submission details for Assignment 2.
    - **screenshots/**: Upload screenshots for Assignment 2.
    - **src/components/**: Upload Assignment 2 source code files/components.

- **Group-Project/**
  - `README.md`: Group project overview and submission details.
  - **screenshots/**: Upload group project screenshots.
  - **client/**: Upload frontend/client code.
  - **server/**: Upload backend/server code.

## How to Upload Files Through GitHub Website

1. Open this repository on GitHub.
2. Navigate to the target folder (for example, `Observation/PDFs` or `Group-Project/client`).
3. Click **Add file** → **Upload files**.
4. Drag and drop files (or choose files from your computer).
5. Add a commit message.
6. Click **Commit changes**.

Repeat these steps for each folder where you want to upload content.
